- MUST use every line below verbatim. MUST NOT rewrite, shorten, merge, reorder, or "improve" approved copy.
- MUST NOT invent copy for any line marked `(to be filled)`. Render it as a visible placeholder that matches the line's register and word budget, so layouts stay honest.

- MUST set each line in the register it is assigned. Registers are defined in `anchor-digital-design-process.md` (Phase 3).
- Word counts are budgets. Placeholder text MUST hit the budget within about 10%.
- The typographic middot `·` is part of the copy. MUST NOT replace it with a hyphen, pipe, or dash.
